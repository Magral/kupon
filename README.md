# Корзина выгоднее (Kupon)

Android-приложение для сравнения стоимости корзины с доставкой в «Ленте» и «Ярче!».

## Возможности версии 0.1.0
- Корзина с отдельными ценами в каждом магазине и количеством товара.
- Учёт доставки, промокодов, скидок на сумму заказа, минимальной суммы и даты окончания акции.
- Учёт совместимости скидки на корзину с бесплатной доставкой.
- Сохранение корзины и предложений на устройстве.
- Ссылки на официальные страницы акций.

Цены на товары, размер доставки и предложения пока добавляются вручную. Это позволяет сверять итог с фактическими ценами заказа; персональные коды нужно подтвердить в аккаунте магазина.

## Сборка
APK для установки создаётся GitHub Actions при обновлении `main` и публикуется в GitHub Releases.
