# Корзина выгоднее (Kupon)

Android-приложение помогает снизить итоговую стоимость доставки продуктов из «Ленты» и «Ярче!».

## Версия 0.2.1
- Сравнение корзины с отдельными ценами по магазинам и учётом доставки.
- Подборка публичных предложений из официальных сайтов, купонных площадок и сообщества.
- Показ источника, срока действия, доступного кода, условий и уровня подтверждения.
- Копирование кода и добавление распознанной скидки в расчёт.
- Ручное добавление персональных предложений, адресных цен и доставки.
- Локальное сохранение корзины и акций.

Автосборщик обновляет ссылки на предложения ежедневно. Сведения сторонних сайтов не равны подтверждению в корзине; персональные коды и применимость к адресу доставки нужно проверять перед оплатой.

## Источники
Список в `scripts/collect_offers.py`: официальные страницы «Ленты» и «Ярче Плюс», Pepper, Picodi, ПромоКодекс, Promokodi.net, ПромКод.ру, Промокодoff, Pikadil и открытая Telegram-лента.

## APK
GitHub Actions собирает установочный APK и публикует его в Releases при изменении Android-приложения.
